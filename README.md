# STO Tracker

STO Tracker is a full‑stack application designed to help track, list, and filter **STOs (Special Technical Orders/ Stock Transfer Orders)** along with material search functionality.  
It provides a client interface for searching and managing STOs, backed by a server that handles listings, filtering, and database operations.

---

## 🚀 Features
- **STO Listing & Filtering** – Browse and filter STOs efficiently.
- **Material Search** – Search STOs by material using the STOSearch component.
- **Client UI** – Built with modern JavaScript, CSS, and HTML.
- **Server API** – Provides routes for STO management and search.
